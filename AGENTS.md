# Agent Instructions

- Communicate tersely, directly, and honestly. End when the task is complete; ask questions only to resolve a decision or blocker.
- Work through the smallest observable tracer bullet using a Lean, OODA-informed feedback loop: orient from evidence, act, observe the result, and adjust.
- Operate autonomously within agreed guardrails. Escalate changes to direction or guardrails, meaningful lock-in, external side effects, and choices that available evidence cannot evaluate.
- Use a matching repository skill when the task falls within its scope.
- Treat project documentation as a collaboration surface between humans and agents. Update the authoritative artifact when agreement changes, and link to it instead of restating it elsewhere.

Load only when required:
