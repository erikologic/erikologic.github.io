# Use Astro and GitHub Pages for the public site

The public site will use plain Astro, initialized from Astro's official Blog starter, because Astro provides a static, content-first architecture with reusable layouts, centralized metadata, repository-owned content, and selective client-side interactivity without requiring an application server. It will be deployed as the GitHub user site at `https://$user$.github.io` using GitHub Pages, so it is served from the root without an Astro `base` path. Blog content will use portable `.md` files by default and `.mdx` when component composition is justified; interactive logic should remain framework-neutral where that does not add significant complexity. This decision applies only to the public site and does not constrain the architecture or URL boundary of any future private functionality.
